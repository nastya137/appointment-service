Данный код представляет собой код бота на Python для Telegram, осуществляющего запись клиентов на консультацию к психологу.

Для корректной работы бота потребуется:
- компьютер, на котором будет храниться Excel-файл с данными о записях;
- токен используемого бота;
- id аккаунта администратора бота.
